Kibo Design System

Tokens del sistema v2, en vivo — y tus decisiones.

Esta página enlaza el CSS real de la app (styles-v2.css + styles-extras.css) y reutiliza las clases kbv-*. Donde hay un fork (variantes que compiten), eliges la opción que prefieres y la decisión se guarda. En un prompt posterior leeré esas decisiones para codificar el Design System canónico — a partir de tus elecciones, no de mi criterio.

Tus decisiones se guardan automáticamente en este navegador. Usa Exportar Design System para generar decisions.json — un spec completo (identidad de marca + todos los tokens + reglas + decisiones) listo para compartir con otros rubros o para codificar el DS canónico. Cada panel Después muestra el efecto en vivo; el panel Antes conserva el estilo actual del sistema para comparar.

Marca y gamificación

Regla de texto sobre color Uso

Los teales, verdes y amarillos son luminosos: no admiten texto blanco pequeño encima. Antes de poner texto sobre un color:

  • Texto blanco solo en superficies grandes (botón con texto ≥18px, o ≥14px en negrita).
  • Para texto pequeño o tipo link, usa el tono -ink del color sobre fondo claro (ej. --kb-primary-ink).
  • Amarillos (coin, medium, wealth) y cyan (will): texto SIEMPRE oscuro, sin excepción.
  • Texto blanco normal pequeño no es seguro sobre el primario (teal); usa --kb-primary-ink.

Acento de marca teal #1CA4A0. Casuística de prestigio (comportamiento esperado)
  • Prestigiar: habilitado solo a Nv. 100 → reinicia a Nv. 1 y sube un grado del escalafón. hoy el handler es no-op (A59/SAN-4)

  • Paragón (solo Maestro): niveles sin tope; cada 100 niveles asciendes un escalón del Trayecto hacia deidad (9 hitos).
